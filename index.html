📸 Google Photos Metadata Toolkit

This tool lets you restore metadata to photos exported from Google Photos using their corresponding .json sidecar files.

  • Drag and drop your image files (e.g. .jpg, .png) into the box below.
  • Make sure each image has a corresponding .json file with the same name (e.g. photo.jpg and photo.json).
  • The app will extract timestamps, location, and other metadata from the JSON file and write it into the image using ExifTool.

Once done, you’ll see the processing results below.
