# Google Photos Metadata Toolkit

Google Photos Metadata Toolkit is a set of tools designed to automate the process of applying and managing metadata for image files, particularly in batch operations. These tools are ideal for efficiently handling metadata for large image collections, especially when working with JSON metadata generated by Google Photos.

## Features

- **Batch Metadata Application**: Apply metadata to multiple image files using corresponding JSON metadata files.
- **Drag-and-Drop Interface**: Easily process files through a user-friendly drag-and-drop interface.
- **Parallel Processing**: Speed up operations by processing multiple files simultaneously.
- **Customizable Output**: Specify output paths and control the number of parallel tasks.
- **Backup Management**: Optionally clean up backup files created during the process.
- **Dependency Checks**: Ensures that all required tools are installed before execution.

## Installation

1. Clone the repository:
   ```bash

   cd google-photos-metadata-toolkit
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the application:
   ```bash
   npm start
   ```

## Usage

### Drag-and-Drop Interface

1. Launch the application using `npm start`.
2. Drag and drop your image files (e.g., `.jpg`, `.png`) into the designated area in the app.
3. Ensure each image has a corresponding `.json` file with the same name (e.g., `photo.jpg` and `photo.jpg.json`).
4. The app will process the files and display the results.

### Command-Line Scripts

#### 1. `generate_file_data.sh`

Generates an input file listing image and corresponding JSON metadata file paths. This file is used as input for the `apply_metadata.sh` script.

**Usage**:
```bash
scripts/generate_file_data.sh [-o output_file] <directory>
```

**Options**:
- `-o output_file`: Specify the output file path for the generated list. Default is `files.data`.
- `-h`: Display help message.

**Example**:
```bash
scripts/generate_file_data.sh -o files.data /path/to/images
```

#### 2. `apply_metadata.sh`

Applies metadata to image files using corresponding JSON files listed in the input file generated by `generate_file_data.sh`.

**Usage**:
```bash
scripts/apply_metadata.sh [-p num_of_processes] input_file
```

**Options**:
- `-p num_of_processes`: Number of processes to use (default is sequential processing).
- `-h`: Display help message.

**Example**:
```bash
scripts/apply_metadata.sh -p 4 files.data
```
